# SketchyUp documentation

Start with the [user guide](USER_GUIDE.md). The rest of this folder is grouped below.

## Using SketchyUp

| Document | What it covers |
| --- | --- |
| [User guide](USER_GUIDE.md) | Task-by-task instructions for the desktop app. The app opens the same text in its built-in guide viewer. |
| [Feature reference](FEATURES.md) | Tools and shortcuts, saving and recovery, the assistant, rendering and animation. |
| [Command-line reference](COMMAND_LINE.md) | `sketchyup-cli`: inspection, scripts, recipes, sessions, MCP and file exchange. |
| [Support matrix](SUPPORT_MATRIX.md) | What the current release supports and tests, and its limits. |
| [Release notes](RELEASE_NOTES.md) | Each release: what changed, upgrade and rollback, known limitations. |
| [Changelog](../CHANGELOG.md) | A shorter list of changes per release. |
